# BBC-6mins-crawler BBC六分钟英语爬虫
语言：[English](README.md) / [简体中文](README-zh.md)
## 简介
这是一套简单的Python脚本，可以从BBC官网批量爬取BBC学英语六分钟英语（BBC Learning English's 6 Minute English）栏目的节目音频和文字稿。
## 开发背景和动机
本项目用于解决个人英语学习过程中BBC 6 Minute English栏目节目保存和离线学习的需求。
## 项目构成及脚本行为
具体来说，本项目目前包含两个相对独立的脚本：JSON生成器和节目下载器。JSON生成器从栏目主页一次性抓取所有可见节目的元数据（标题、链接等）并保存在JSON文档里。下载器读取JSON数据，按从旧到新顺序串行下载文字稿和媒体文件，对html文件中的文字稿进行简单处理后以txt格式保存，并调用ffmpeg，将其他媒体格式转码为音频格式，同时向原JSON文件中补充`media_download_url`等键值对。
## 使用说明
使用时，请将所有脚本及生成的json文件置于同一工作目录之下。用户可以在下载器源码文件（downloader.py）里修改节目保存路径常量等配置。具体内容以源码为准。暂不提供独立配置文件。ffmpeg需自备并正确设置环境变量以便脚本能够访问，否则转码功能将失效。终端默认输出语言为简体中文。
