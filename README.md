# BBC-6mins-crawler
Languages: [English](README.md) / [简体中文](README-zh.md)

A simple set of python scripts which can crawl in batches the audios and scripts of the 6 Minutes English programs from the official website of BBC Learning English.

Specifically, it currently contains 2 relatively independent scripts, the json generator and the downloader respectively. The json generator captures the meta data of all available programs in one go and saves them in a json document. Then the downloader reads the json data and gets both the transcript and the audio file one by one, and add some extra key-value pairs like media_download_url to the json file.

The main part of the scripts of this simple crawler project is generated by AI (Deepseek LLM, specifically), while the human author created this idea and shoulders the work of code review and debugging with AI's assistance.
